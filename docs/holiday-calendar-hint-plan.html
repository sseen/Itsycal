节假日日历提示方案

目标是不改变默认行为，只在用户当前地区存在可匹配的系统节假日日历、 但该日历没有被 Itsycal 勾选时，给一个可关闭的轻量提示。 实现由 EventCenter 检测、主窗口横幅、设置页一次性高亮三部分组成。

整体流程

显示条件

  1. 未关闭：kHolidayHintDismissed 不是 YES。
  2. 已授权：EventKit 日历权限可用；未授权时不显示。
  3. 本地匹配：当前地区为 CN 或 JP，并存在标题关键词匹配的订阅日历。
  4. 尚未勾选：任何匹配的节假日日历已勾选时，都不再提示。

第一版只提示系统中已经存在的订阅日历，不负责引导用户新增订阅。

主窗口横幅

改动清单

  • EventCenter.h/m新增检测方法、地区关键词表、可测试标题匹配函数。
  • ViewController.m新增横幅视图、显隐刷新、关闭和跳转处理。
  • PrefsVC.h/m新增切到 General tab 并转发 pending hint 的入口。
  • PrefsGeneralVC.h/m按 calendar identifier 滚动到目标行并显示一次性 transient popover。
  • Itsycal.h/m新增 kHolidayHintDismissed 用户默认键。
  • Localizable.strings补横幅、关闭按钮和 popover 文案。
