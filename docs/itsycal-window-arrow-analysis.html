Itsycal 顶部三角箭头实现分析

实现集中在 Itsycal/main/ItsycalWindow.m： 透明无边框 NSPanel 负责窗口行为， 自绘 frame view 负责外形，NSVisualEffectView 通过 maskImage 获得同样的圆角和箭头裁剪。

三层结构

Frame view 画边框和箭头轮廓 Content view 内嵌在带 margin 的安全区域

实现机制

  1. 窗口层： ItsycalWindow 是透明、无边框的 NSPanel，真正内容被嵌入自绘 frame view。
  2. 形状绘制： 主体是圆角矩形，顶部箭头由两段三次贝塞尔曲线拼出， 所以观感接近系统 popover。
  3. 箭头定位： 窗口可为避开屏幕边缘整体左移，箭头使用转换后的 frame 坐标继续指向状态栏图标。
  4. 毛玻璃裁剪： NSVisualEffectView 铺满 frame view， 再用与绘制路径一致的 maskImage 裁剪。

箭头路径

可优化点

  1. 1. 抽出路径构造函数，让 drawRect: 和 invalidateCornerImage 共享同一份 “圆角矩形 + 箭头”路径。
  2. 2. 将废弃的 lockFocus 改为 imageWithSize:flipped:drawingHandler:， 让蒙版按目标环境绘制，减少 Retina/非 Retina 切换时的边缘风险。
  3. 3. 移除重复 mask 生成的脆弱点和无效的 VFL metrics， 减少维护噪声。
  4. 4. 给箭头位置加显式 “已设置” 状态，并钳制到可绘制范围， 避免使用 0 当哨兵值以及箭头贴近圆角。

结论

当前架构方向正确：不用换成 NSPopover， 因为现有窗口还承担非激活面板、菜单窗口层级、pin 住不消失等行为。 这次实现应保持架构不变，只收敛路径来源、更新蒙版生成方式， 并补上箭头坐标健壮性。
