日历格子标记绘制优化方案

MoCalCell.drawRect: 同时绘制底部事件圆点、右上角中国节假日角标和初一红线。 优化重点是把三类标记从同一条底部窄带里拆开，并让尺寸进入 Sizer，不改变最多 3 个事件点、 颜色来源或节假日状态逻辑。

现状问题

优化目标

  1. 圆点位置：从底部 1pt 改为 2pt，避开选中/悬停描边，同时不继续挤压农历文字。
  2. 跟随大号模式：圆点直径默认 4pt，大号模式 5pt。
  3. 角标收进高亮边界：用内缩后的 bounds 作为绘制基准，减少与圆角高亮冲突。
  4. 红线换位：初一红线从底部横线改为左侧竖条，避开圆点、农历文字和底部选中描边。
  5. 尺寸集中：圆点 y、角标半径、角标 inset、竖条几何、农历文字偏移都进入 Sizer。
  6. 代码收敛：1/2/3 个点统一循环绘制，删掉无效阴影保存/裁剪逻辑。

最终组合

  1. 初一标记移到左侧：x = 2pt、宽 2pt、上下内缩约 10pt，不再占底部。
  2. 尺寸变化时重算：竖条 frame 由 layout/sizeChanged: 更新，修掉大号格子仍按旧 bounds 的问题。
  3. 颜色统一：左侧竖条与当天高亮一致，使用 NSColor.systemRedColor。
  4. 农历文字根治：收紧 attributed string 行高，并把双行文本整体上移约 1.5pt，给底部圆点留空间。

实现清单

  • Sizer.h/m新增 cellDotOriginY、cellHolidayBadgeRadius、cellHolidayBadgeInset、初一竖条几何、农历行高和文本偏移，并把大号圆点改为 5pt。
  • MoCalCell.m圆点使用循环绘制，根据点数计算居中偏移；默认空数组仍画一个文字色圆点。
  • MoCalCell.m右上角角标使用 NSInsetRect(bounds, inset, inset) 作为边界，并删除同色描边。
  • MoCalCell.m初一红线改成左侧竖条，frame 跟随 bounds/尺寸模式更新。
  • MoCalendar.m农历双行文本使用收紧行高，并通过 cell 的中心约束整体上移。

不改动事件点最多 3 个的截断策略，也不改动中国节假日状态来源；这些属于上层数据策略。
